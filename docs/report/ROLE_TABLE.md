# Role table (five-field contracts)

Generated from `ta2/agents.py` and `ta2/supervisor.py` by `scripts/build_report_tables.py`; the backend serves the same objects at `GET /api/agents/contracts`.

| Role | Goal | Tools | Inputs → outputs | Limits |
|---|---|---|---|---|
| **Proposer** | Select the next empty cell (minimum-remaining-values or first-empty) and list its legal candidates in a given order. | candidate generator (sudoku_rules.candidates), optional local qwen2.5:3b ordering hint (advisory, filtered) | IN: 4x4 board, strategy, order. OUT: zero-based cell [row, col] (or None if full) and a list of legal candidates. | Cannot commit a move; its output is always a permutation of the deterministic legal set (anything else is discarded). |
| **Evaluator / RuleChecker** | Assess whether a single candidate placement is legal and explain any rejection. | row/column/box validator (sudoku_rules.placement_check) | IN: board, cell [row, col], value. OUT: Verdict(ok, reason_code, reason). | Judges one placement only; cannot claim the puzzle is solved from partial legality. |
| **Verifier** | Verify partial states for consistency, detect dead ends, and verify that a complete board is a valid solution preserving the clues. | sudoku_rules.find_conflicts, sudoku_rules.is_complete_valid, sudoku_rules.zero_candidate_cell | IN: board (+ original puzzle). OUT: Verdict(ok, reason_code, reason). | Never accepts an incomplete or rule-violating board, or one that changes an original clue. |
| **Verifier / Backtracker** | Detect dead ends, prune failed branches, restore the exact parent board, and record every decision as a trace event. | SearchEngine (ta2.search), state stack, VerifierAgent | IN: partial board/search state. OUT: branch status, restore action, trace events, verified solution or None. | Must restore the exact parent state; cannot accept an unverified solution; bounded by max_nodes and a deadline. |
| **Supervisor** | Coordinate the agents, enforce execution policy, collect results and return a verified winner or an explicit failure. | agent router, ToolRunner (retry/fallback), trace recorder, vote tally (verified solutions only) | IN: puzzle + run configuration. OUT: routing trace, attempt records, VoteResult, final verified solution or failure code. | Hard MAX_HOPS, per-run timeout, node and tool-call budgets; invalid, partial or timed-out attempts never vote; never returns an unverified winner. |
